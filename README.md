# 📰 LocalNews — Hyperlocal News for 300+ Indian Cities

A city-first news discovery platform that brings together local news from 300+ cities across India in one place. Find fresh updates from your city in Hindi and English.

**Live:** [localnews.meenai.in](https://localnews.meenai.in/)

## Features

- 🏙️ Browse local news from 300+ Indian cities
- 🗺️ State-wise coverage across India
- 🌐 Hindi + English reading experience
- 🔗 Every story links back to the original publisher

## Why this project

Local news is hard to discover — it's scattered across dozens of websites. LocalNews puts your city's civic, crime, weather, business, and sports updates in one clean feed.

## Development

```sh
git clone https://github.com/meenaispeaks6-droid/localnewss.git

npm i
npm run dev
```
